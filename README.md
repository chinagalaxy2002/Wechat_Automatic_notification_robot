# 微信通知助手

一个基于Python的微信批量消息发送工具，可以自动读取联系人名单并发送自定义消息。
#编译好的文件见右侧release处下载。#

## 功能特点

- 批量发送微信消息
- 支持从文件导入联系人名单
- 图形用户界面，操作简单
- 实时显示发送进度
- 详细的日志记录
- 支持发送过程中的中断

## 系统要求

- Windows 操作系统
- Python 3.6 或更高版本
- 微信桌面版（需要已登录）

## 安装步骤

1. 克隆或下载本项目到本地

2. 安装依赖包：
```bash
pip install -r requirements.txt
```

3. 确保已安装并登录微信桌面版

## 使用方法

1. 运行程序：
```bash
python main.py
```

2. 在程序界面中：
   - 点击"登录"按钮连接微信
   - 上传包含联系人名单的文件（每行一个名字）
   - 在文本框中输入要发送的消息内容
   - 点击"发送"按钮开始批量发送

3. 发送过程中：
   - 可以查看实时进度
   - 可以随时中断发送
   - 发送完成后会显示成功/失败统计

## 注意事项

1. 使用前请确保：
   - 微信桌面版已安装并登录
   - 联系人名单格式正确
   - 名单中的名字与微信中的联系人名称完全匹配

2. 发送过程中：
   - 请勿操作电脑，以免影响自动化操作
   - 保持微信窗口可见
   - 不要最小化微信窗口

3. 如果遇到问题：
   - 查看 `wechat_notifier.log` 日志文件
   - 确保网络连接正常
   - 检查微信是否正常登录

## 文件说明

- `main.py`: 程序入口
- `wechat_bot.py`: 微信机器人核心类
- `ui_main.py`: 用户界面实现
- `utils.py`: 工具函数
- `requirements.txt`: 依赖包列表
- `wechat_notifier.log`: 日志文件

## 常见问题

1. 无法连接微信
   - 检查微信是否已登录
   - 重启微信和程序

2. 发送失败
   - 检查联系人名称是否正确
   - 确认微信窗口是否被遮挡
   - 查看日志文件了解具体原因

3. 程序无响应
   - 检查是否安装了所有依赖
   - 确认Python版本是否正确
   - 查看系统资源使用情况
